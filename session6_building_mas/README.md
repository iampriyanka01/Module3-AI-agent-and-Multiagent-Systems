# Building MAS Lab (Session 6): Building Multi-Agent Systems with LangChain and CrewAI

Covers everything in the session PDF, notebook 6A (*Multi-Agent Systems with LangChain*) and notebook 6B (*Meet CrewAI*),
so you can learn the session from the app alone. The start page has a table showing where each part of the PDF and the
notebooks is covered.

Keep these files together in ONE folder:

    app.py                        the app (run this one)
    crew_engine.py                PDF desks + "mini CrewAI" + recorded CrewAI prompts
    lc_engine.py                  notebook 6A: data, tools, the three desks, the step limit
    crewai_recordings.json        prompts recorded from the real CrewAI 1.15
    langchain_tool_schemas.json   tool descriptions generated by LangChain 1.4
    assets/                       the notebooks' diagrams

    pip install streamlit pandas
    streamlit run app.py

## How the demos stay faithful

- **Demo mode** (default) needs no API key, and needs neither LangChain nor CrewAI installed. The agents' wording is scripted and all data is pretend (as in the notebooks).
- Exact: the notebook's data, tools and refund arithmetic (copied word for word), and the model-call counts.
- Measured on **LangChain 1.4** with a stand-in model: how `create_agent` counts steps against `recursion_limit`, and the tool descriptions LangChain generates from docstrings.
- Recorded from the real **CrewAI 1.15.28** with a stand-in model: every prompt shown on page 8. With Gemini, CrewAI may send the tool list through Gemini's native tool calling instead of inside the text.
- Checked on CrewAI 1.15: a hierarchical crew needs `manager_llm` or `manager_agent`, and a manager agent with tools makes `kickoff()` fail ("Manager agent should not have tools"). The PDF's manager-with-tools example no longer works.
- The "mini CrewAI" on pages 9 to 11 is a small teaching model, not the CrewAI library. The CrewAI code it generates was checked to build a real Crew.
- **Live mode** (Gemini) is optional: it lets Gemini write the text on pages 10 and 11. It was not tested end to end.
