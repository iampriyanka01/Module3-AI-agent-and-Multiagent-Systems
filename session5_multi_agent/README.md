# MAS Lab (Session 5): Intro to Multi-Agent Systems

Keep `app.py` and `mas_engine.py` together in ONE folder.

    pip install streamlit pandas
    streamlit run app.py

You only run `app.py`. `mas_engine.py` is imported by it and must sit beside it; do not run it on its own.
Demo mode needs no key (scripted agents, pretend data). Live mode (Gemini) is optional and was not tested end to end.
