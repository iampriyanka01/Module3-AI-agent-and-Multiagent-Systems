# MAS Lab (Session 5): Intro to Multi-Agent Systems

Keep `app.py`, `mas_engine.py` and the `assets/` folder (the notebook's diagrams) together in ONE folder.

    pip install streamlit pandas
    streamlit run app.py

You only run `app.py`. `mas_engine.py` is imported by it and must sit beside it; do not run it on its own.
Demo mode needs no key (scripted agents, pretend data). Live mode (Gemini) is optional and was not tested end to end.

Covers the session PDF and the Session 5 notebook, including its seven diagrams, so you can learn the session from the app alone. The start page has a table showing where each part is covered.
